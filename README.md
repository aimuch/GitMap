# OpenNotion

一个完全运行在本机的块编辑笔记与知识库工作区：页面无限嵌套，支持多视图数据库与本地多模型 AI 助手，所有笔记内容以 JSON 文件保存在本地磁盘，不依赖任何云笔记服务，也不需要注册账号。

## 运行

```bash
npm install
npm run dev
```

然后打开 <http://localhost:5273>。

想用构建后的版本运行（更快，没有热更新）：

```bash
npm start
```

## 桌面版

除了在浏览器里用，也可以打包成双击即用的桌面应用（基于 Electron），不需要对方安装 Node.js。

```bash
npm run desktop
```

上面这条是直接运行桌面版。打安装包：

| 命令 | 产物（在 `release/` 目录） | 在哪里能构建 |
| --- | --- | --- |
| `npm run dist:mac` | `.dmg` 安装镜像 | macOS |
| `npm run dist:win` | 安装程序 `.exe` + 免安装 `.zip` | Windows，或 Intel 芯片 / 装了 Rosetta 的 Mac |
| `npm run dist:win:zip` | 免安装 `.zip`，解压后运行 `OpenNotion.exe` | 任何系统 |
| `npm run dist:linux` | `.AppImage` + `.tar.gz` | Linux，或 Intel 芯片 / 装了 Rosetta 的 Mac |
| `npm run dist:linux:tar` | `.tar.gz`，解压后运行 `open-notion` | 任何系统 |

要一次得到三个平台的正式安装包，最省事的是用 `.github/workflows/desktop.yml`：把项目推到 GitHub 后在 Actions 里手动运行，它会分别在三种系统上构建并提供下载。

- **多设备同步与数据导入**：所有笔记都是独立的 JSON 文件。在桌面版左下角点齿轮“设置 → 数据与多端同步”（或菜单“文件 → 更改数据存储目录”），把数据目录指向 **iCloud Drive、群晖 Synology Drive、SMB/NAS 挂载目录、OneDrive 或坚果云** 中的同一个文件夹，即可在多台电脑之间同步工作区；切换回窗口时会自动增量读取磁盘更新。要把另一份工作区的笔记并进来，点“合并其他文件夹数据…”即可（已存在的页面不会覆盖）。
- **没有签名证书**：安装包没有经过 Apple / 微软的开发者签名。拿到别的电脑上第一次打开时，macOS 会提示“无法验证开发者”（到“系统设置 → 隐私与安全性”里点“仍要打开”），Windows 会弹出 SmartScreen 提示（点“更多信息 → 仍要运行”）。要去掉这些提示，需要购买开发者证书并在打包时配置。
- **只在本机可访问**：桌面版内置的服务只监听 `127.0.0.1`，局域网里的其他设备访问不到。

## 功能

- **块编辑器**：输入 `/` 插入标题、折叠列表、待办、引用、**双栏 / 三栏 / 四栏并排分栏**（支持拖拽分隔线调宽与动态增减栏数）、**提示框（Callout）**、**自动目录（TOC）**、**结构化数学公式块与行内公式**（支持分式、根式、上下标、大型求和积分与矩阵实时排版）、**Mermaid 图表块**（实时渲染流程图、时序图与饼图，支持分屏编辑）、**网页与本地 PDF 内嵌块**（自动适配本地 PDF、Bilibili、YouTube、Figma 画布及拖拽调高）、**动作按钮块**（一键在下方插入带时间戳待办/段落、新建子页或唤起 AI）、**网页书签卡片**、表格、代码块（带语法高亮）、图片、视频、音频、文件等。
- **页面树与双向链接**：页面无限嵌套，侧边栏拖拽可排序或改变层级；输入 `@` 链接其他页面，目标页面顶部会自动汇总展示**反向链接（Backlinks）**。
- **同步块**：输入 `/同步` 新建或插入已有的同步块，在多个页面（以及同一页面的多处）实时同步显示与编辑同一份内容；回收站底部支持一键清理未被引用的闲置同步块。
- **页面排版、封面焦点调整、锁定与批注**：页面右上角菜单支持切换**默认 / 衬线 / 等宽**三种字体、**小字号**、**全宽显示**与**锁定页面（防误改只读）**，并展示实时字数统计；上传自定义封面图后支持点“调整位置”上下拖动裁剪焦点；标题区支持添加**页面批注**；长文档右侧自动浮现**目录大纲**。
- **内置与自定义模板**：空白页面上点“使用模板”可一键套用会议纪要、待办清单、周计划、读书笔记四个内置模板；在任意页面菜单里选“设为模板”，还能把自己的页面（连同子页面与内嵌数据库）变成模板。
- **页面历史**：编辑正文页面时自动留存历史快照，在页面菜单“页面历史”里可以预览旧版本并一键恢复。
- **导入与导出**：侧边栏底部“导入 Notion 导出包”支持直接导入 Notion 的 `Markdown & CSV` 压缩包（含分卷嵌套 zip）；页面支持导出为 **Markdown** 或独立排版的 **HTML**，数据库支持导出为 **CSV**。
- **搜索、收藏与回收站**：`⌘K` / `Ctrl+K` 全文搜索标题、正文和数据库属性；支持浅色 / 深色 / 跟随系统主题。

| 快捷键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 全局搜索（在编辑器里选中文字时是“添加链接”） |
| `⌘J` / `Ctrl+J` | 打开全局 AI 助手与工作区知识库问答 |
| `⌘,` / `Ctrl+,` | 打开工作区设置（外观、数据同步、AI 模型、导入、回收站） |
| `⌘\` / `Ctrl+\` | 收起或展开侧边栏 |
| `/` | 块命令与内联 AI 菜单 |
| `@` | 提及并链接到页面 |

## 多模型 AI 助手

在侧边栏左下角点齿轮图标打开“设置 → AI 模型服务”（或按 `⌘J` / `Ctrl+J` 打开面板点右上角齿轮），即可按需接入国内外主流大模型或自定义接口：

- **内置国产大模型预设**：
  - **DeepSeek（深度求索）**：`deepseek-chat`、`deepseek-reasoner`（支持展示思考推理链）
  - **Kimi（月之暗面）**：`kimi-k2-0905-preview`、`moonshot-v1-auto`、`moonshot-v1-128k`
  - **豆包（火山方舟）**：支持直接填豆包模型名或火山方舟推理接入点 ID（`ep-...`）
  - **通义千问（阿里云百炼）**：`qwen-max`、`qwen-plus`、`qwen-turbo`、`qwq-plus`
  - **智谱清言（GLM）**：`glm-4-plus`、`glm-4-air`、`glm-4-flash`
- **内置国外大模型预设**：
  - **OpenAI**：`gpt-4.1`、`gpt-4o`、`gpt-4o-mini`、`o3-mini`
  - **Anthropic Claude**：`claude-sonnet-4-20250514`、`claude-3-7-sonnet-latest`、`claude-3-5-haiku-latest`
  - **Google Gemini**：`gemini-2.5-pro`、`gemini-2.5-flash`
- **本地与自定义模型**：
  - **Ollama 本地模型**：默认对接 `http://127.0.0.1:11434/v1`，免填 API Key，支持一键读取本机已安装的模型列表。
  - **完全自定义服务与模型**：可添加任意多个自定义服务商（如硅基流动、OpenRouter、OneAPI / NewAPI、vLLM、LM Studio 或企业内部网关），自由选择 `OpenAI 兼容`、`Anthropic Messages` 或 `Google Gemini` 三种协议，自定义 Base URL、请求头、模型 ID 列表、温度与全局提示词，并提供一键“测试连接”。
- **使用方式**：
  - **全工作区知识库问答（`⌘J`）**：自动从本地页面与数据库中检索相关资料回答问题，附带可点击跳转的引用页面标签，支持将回复一键存为新页面或插入当前页。
  - **编辑器内联写作（`/ai` 或选中文字点悬浮胶囊）**：支持润色改写、纠错、精简、扩写、切换语气、多语种翻译（中/英/日/韩）、总结要点、顺着续写、提取待办、头脑风暴及连续追问修改，生成结果自动解析为原生块插入或替换。
  - **数据库 AI 自动填充**：在数据库的“文本”列设置 AI 填充指令后，可按单元格单行生成，也可一键为整列所有行批量生成摘要、分类或翻译。
- **隐私说明**：API Key 以 `0600` 权限保存在本机 `data/ai.json`（也可通过环境变量 `DEEPSEEK_API_KEY`、`MOONSHOT_API_KEY`、`ARK_API_KEY`、`DASHSCOPE_API_KEY`、`ZHIPU_API_KEY`、`OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY` 提供），请求由本机进程直接发往所选模型接口，不经过任何第三方中转。

## 数据库

在空白页面上点“表格”“看板”“列表”或“日历”，或在编辑器里输入 `/数据库`，就能新建一个数据库；输入 `/链接数据库` 可把已有的数据库嵌入其他页面（每个链接数据库**独立保存自己的视图、筛选、排序与分组配置**，互不干扰）：

- **侧边抽屉（Side Peek）**：点击数据库中的任意行或卡片，默认在右侧滑出抽屉面板编辑属性、批注与正文，无需离开当前视图；按住 `⌘` / `Ctrl` 点击或点抽屉左上角“展开为整页”可整页打开。
- **子任务层级与自动化规则**：
  - **无限层级子任务（Sub-items）**：在工具栏“自动化”菜单开启子任务层级后，表格与列表视图支持逐级展开或折叠子任务，并在悬停时一键新建子项。
  - **数据库自动化（Automations）**：支持配置“新建一行时”或“当某属性变为指定值时”自动执行多项动作（如状态变为已完成时自动将截止日设为当天日期、自动勾选归档或自动新建跟进行）。
- **属性类型**：
  - 基础类型：文本（可选配 **AI 自动填充**）、数字、单选、多选、日期、复选框、网址；支持改名、转换类型、排序和按视图控制**属性显示 / 隐藏**。
  - **按钮属性（Button）**：在行内提供可点击的自定义动作按钮，一键批量修改当前行多个属性或新建关联行。
  - **关联**与**汇总**：跨数据库或同库自关联行，并按关联做显示原值、计数、求和、平均值、最小 / 最大值汇总。
  - **公式**：使用自写词法与语法解析器安全求值（无 `eval`），支持算术、比较、逻辑运算及 `prop`、`if`、`round`、`concat`、`dateBetween`、`today` 等函数。
- **八种视图**：
  - **表格**：支持拖拽列宽、手动顺序下行拖拽排序、**按任意属性折叠分组（Group by）**、子任务树展开以及**底部汇总计算行**（总数、已填/未填、完成率、求和、均值、最大/最小值）。
  - **看板**：按单选属性分列拖拽卡片，支持新建分组与就地输入卡片名称。
  - **列表**：紧凑列表展示标题与关键属性，同样支持按任意属性折叠分组与子任务层级。
  - **日历**：按日期属性排布（周一开头），支持拖拽改期。
  - **画廊**：带封面的卡片网格展示，支持切换**紧凑 / 适中 / 大图**尺寸以及**页面封面 / 属性摘要 / 不显示封面**预览源。
  - **时间轴**：按开始与结束日期绘制可跨多天的时间条，支持配置**前后置任务依赖贝塞尔连线**，当排期倒挂冲突时自动以红色虚线高亮预警。
  - **图表**：内置矢量**柱状图、折线趋势图与环形占比图**，支持按任意属性分组统计行数、数值求和、均值或最大值。
  - **表单**：将数据库字段直接渲染为结构化数据收集表单（Forms），填写提交后自动生成新记录并触发自动化规则。
- **搜索、多层嵌套条件组（`AND / OR` 组合）高级筛选、多列排序与 CSV 导出**。

## 数据存在哪里

```
data/
  pages/<页面 id>.json      每个页面一个文件：标题、图标、排版、批注、属性、正文（BlockNote JSON）
  history/<页面 id>/*.json  正文页面的历史版本快照
  uploads/                  上传的图片和附件
  ai.json                   本地大模型接口与密钥配置（权限 0600）
```

- 备份或迁移：直接复制 `data/` 目录即可，或在桌面版里用“文件 → 从文件夹导入数据…”。
- 换一个存储位置：`OPEN_NOTION_DATA=/path/to/dir npm run dev`。
- `data/` 默认在 `.gitignore` 里；如果想用 git 给笔记做版本管理，请注意不要把含密钥的 `data/ai.json` 推到公开仓库。

## 项目结构

```
server/api.ts        本地存储、历史版本、反向链接与工作区检索 API
server/ai.ts         多模型流式代理（OpenAI 兼容 / Anthropic / Gemini）与网页书签抓取
server/seed.ts       首次启动时写入的示例页面与示例数据库
shared/types.ts      前后端共用的类型定义
src/machines.ts      核心状态机与纯状态转移（自动保存、浮层栈、加载、内联 AI、历史、导入、拖拽隔离）
src/store.ts         前端状态存储、防抖自动保存与失败重试、路由与诊断快照
src/ai.ts            前端 AI 流式客户端、快捷指令模板与数据库自动填充
src/db.ts            数据库属性、子任务树、分组、嵌套筛选、自动化执行器与 CSV 导出
src/formula.ts       公式词法分析、语法解析与安全求值器
src/math.tsx         TeX / LaTeX 数学公式语法解析与结构化排版组件
src/mermaidSvg.tsx   零依赖离线 Mermaid 矢量图（流程图 / 时序图 / 饼图）渲染引擎
src/notionImport.ts  Notion 导出包（zip）浏览器端解压与导入
src/templates.ts     内置页面模板
src/components/      侧边栏、页面视图、多栏布局、编辑器扩展块、AI 弹窗、设置中心与八种数据库视图
electron/main.ts     桌面版主进程：启动本地服务、多端同步目录切换与数据文件夹合并
```

服务只监听 `localhost`，并且拒绝跨域的写请求。它没有登录机制，所以不要用 `--host` 把它暴露到不可信的网络上。

## 尚未实现与已知限制

- **尚未实现**：多人实时在线协同光标、公开网页一键发布（Publish to Web）、跨多数据库全局主页（My Tasks）及第三方 Webhook 集成。
- **已知限制**：
  - 页面历史仅对正文页面生效，大约每 10 分钟保存一版，单个页面最多保留 40 版。
