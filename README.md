# OpenNotion

一个完全运行在本机的块编辑笔记工作区：页面可以无限嵌套，内容以 JSON 文件保存在本地磁盘，不依赖任何云服务，也不需要账号。

## 运行

```bash
npm install
npm run dev
```

然后打开 <http://localhost:5273>。

想用构建后的版本运行（更快，没有热更新）：

```bash
npm start
```

## 桌面版

除了在浏览器里用，也可以打包成双击即用的桌面应用（基于 Electron），不需要对方安装 Node.js。

```bash
npm run desktop
```

上面这条是直接运行桌面版。打安装包：

| 命令 | 产物（在 `release/` 目录） | 在哪里能构建 |
| --- | --- | --- |
| `npm run dist:mac` | `.dmg` 安装镜像 | macOS |
| `npm run dist:win` | 安装程序 `.exe` + 免安装 `.zip` | Windows，或 Intel 芯片 / 装了 Rosetta 的 Mac |
| `npm run dist:win:zip` | 免安装 `.zip`，解压后运行 `OpenNotion.exe` | 任何系统 |
| `npm run dist:linux` | `.AppImage` + `.tar.gz` | Linux，或 Intel 芯片 / 装了 Rosetta 的 Mac |
| `npm run dist:linux:tar` | `.tar.gz`，解压后运行 `open-notion` | 任何系统 |

要一次得到三个平台的正式安装包，最省事的是用 `.github/workflows/desktop.yml`：把项目推到 GitHub 后在 Actions 里手动运行，它会分别在三种系统上构建并提供下载。

- **数据位置与导入**：桌面版的数据在系统的用户数据目录里，和网页版的 `data/` 是两份。应用菜单“文件 → 打开数据文件夹”可以直接打开；要把网页版或另一份工作区的笔记并进来，点菜单“文件 → 从文件夹导入数据…”选择对方的 `data` 文件夹即可（已存在的页面和附件不会覆盖）。
- **没有签名证书**：安装包没有经过 Apple / 微软的开发者签名。拿到别的电脑上第一次打开时，macOS 会提示“无法验证开发者”（到“系统设置 → 隐私与安全性”里点“仍要打开”），Windows 会弹出 SmartScreen 提示（点“更多信息 → 仍要运行”）。要去掉这些提示，需要购买开发者证书并在打包时配置。
- **只在本机可访问**：桌面版内置的服务只监听 `127.0.0.1`，局域网里的其他设备访问不到。

## 功能

- **块编辑器**：输入 `/` 插入标题、列表、待办、引用、表格、代码块（带语法高亮）、图片、视频、文件等；拖动块左侧的手柄可以排序和嵌套；选中文字设置样式、颜色和链接。
- **页面树**：页面无限嵌套；在侧边栏拖拽可以排序或移动到其他页面下。
- **页面链接**：输入 `@` 链接到其他页面；用 `/子页面` 在当前页面下新建页面。链接会跟随目标页面的标题和图标自动更新。
- **同步块**：输入 `/同步` 新建或插入已有的同步块，在多个页面中展示和编辑同一份内容。
- **内置与自定义模板**：空白页面上点“使用模板”可一键套用会议纪要、待办清单、周计划、读书笔记四个内置模板；在任意页面菜单里选“设为模板”，还能把自己的页面（连同子页面与内嵌数据库）变成可复用的模板。
- **页面历史**：编辑正文页面时会自动留存历史快照，在页面菜单“页面历史”里可以预览旧版本并一键恢复（恢复前会先把当前内容存成一版）。
- **从 Notion 导入**：侧边栏底部“导入 Notion 导出包”支持选择 Notion 导出的 `Markdown & CSV` 压缩包（含嵌套分卷 zip），在本地完成解压、层级还原、正文转换、图片与附件上传以及 CSV 数据库识别。
- **图标与封面**：为页面设置 emoji 图标，以及渐变、纯色或上传图片作为封面。
- **搜索**：`⌘K` / `Ctrl+K`（或 `⌘P`）全文搜索页面标题、正文和数据库属性值。
- **收藏与回收站**：收藏常用页面；删除的页面连同子页面进入回收站，可以恢复或永久删除。
- **其他**：浅色 / 深色 / 跟随系统主题、全宽布局、创建副本、导出 Markdown、自动保存。

| 快捷键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 搜索（在编辑器里选中文字时是“添加链接”） |
| `⌘\` / `Ctrl+\` | 收起或展开侧边栏 |
| `/` | 命令菜单 |
| `@` | 链接到页面 |

## 数据库

在空白页面上点“表格”“看板”或“日历”，或在编辑器里输入 `/数据库`，就能新建一个数据库：

- **数据库（内嵌）**：直接嵌在正文里，和文字、图片混排；它的数据是当前页面下的一个数据库子页面，点标题旁的“打开”可以整页查看。
- **数据库（整页）**：新建一个数据库子页面并跳转过去。
- **链接已有数据库**：输入 `/链接数据库` 把已有的数据库嵌到其他页面里，和原数据库共用同一份数据。

数据库的每一行都是一个普通页面，可以点开写正文。

- **属性类型**：
  - 基础类型：文本、数字、单选、多选、日期、复选框、网址；点列头可以改名、改类型（自动尽量转换已有值）、排序、删除。
  - **关联**：关联到任意数据库中的行，在单元格里搜索并多选。
  - **汇总**：顺着某个关联属性读取对方数据库的属性，支持显示原值、计数、求和、平均值、最小值、最大值。
  - **公式**：使用自写的词法与语法解析器求值（不使用 `eval`），支持四则与取模运算、比较与逻辑运算、`prop("属性名")`、`if`、`round` / `floor` / `ceil` / `abs`、`min` / `max` / `sum`、`concat` / `length` / `contains` / `lower` / `upper`、`empty`、`toNumber`、`today` / `now`、`dateBetween` 等函数；写错时会显示 `#错误` 并提示具体原因。
- **视图**：表格、看板、日历、画廊和时间轴，可以添加多个视图、重命名、删除。
  - **表格**：拖动列边界调整列宽并随视图保存；在“手动顺序”下拖动行首手柄调整行顺序。
  - **看板**：按单选属性分组，卡片可在列之间拖动，也可以直接添加新分组；在工具栏或列内点“新建”后可直接就地输入卡片名称。
  - **日历**：按日期属性排布（周一开头），点某一天的 `+` 在当天新建，拖动卡片改日期，拖到下方“未安排日期”清除日期。
  - **画廊**：把每一行展示为带封面与属性摘要的卡片网格。
  - **时间轴**：按开始与结束日期属性绘制可跨多天的时间条，支持按两周步进浏览或一键回到今天。
- **搜索、筛选与排序**：
  - “搜索”按名称和属性值的文字快速过滤，不保存。
  - “筛选”按属性设条件（包含、等于、早于、为空、已勾选等，随属性类型而定），多个条件可选“全部满足”或“满足任一”，条件随视图保存。在带筛选的视图里新建的行会自动带上能通过条件的属性值。
  - “排序”按任意属性（包括计算结果）升降序排列。
- **导出**：数据库页面右上角菜单里可以导出为 CSV。

## 数据存在哪里

```
data/
  pages/<页面 id>.json      每个页面一个文件：标题、图标、层级、属性、正文（BlockNote JSON）
  history/<页面 id>/*.json  正文页面的历史版本快照
  uploads/                  上传的图片和附件
```

- 备份或迁移：直接复制 `data/` 目录即可，或在桌面版里用“文件 → 从文件夹导入数据…”。
- 换一个存储位置：`OPEN_NOTION_DATA=/path/to/dir npm run dev`。
- `data/` 默认在 `.gitignore` 里；如果想用 git 给笔记做版本管理，把那一行删掉。

## 项目结构

```
server/api.ts        本地存储与历史版本 API（只用 Node 内置模块），挂在 Vite 或桌面版服务上
server/seed.ts       首次启动时写入的示例页面与示例数据库
shared/types.ts      前后端共用的类型定义
src/store.ts         前端状态、防抖自动保存、路由
src/db.ts            数据库属性、筛选、排序、汇总与 CSV 导出逻辑
src/formula.ts       公式词法分析、语法解析与安全求值器
src/notionImport.ts  Notion 导出包（zip）浏览器端解压与导入
src/templates.ts     内置页面模板
src/components/      侧边栏、页面视图、编辑器、同步块、历史版本、各数据库视图等
electron/main.ts     桌面版主进程：启动本地服务、窗口管理与数据文件夹导入
```

服务只监听 `localhost`，并且拒绝跨域的写请求。它没有登录机制，所以不要用 `--host` 把它暴露到不可信的网络上。

## 尚未实现与已知限制

- **尚未实现**：多人实时协作与多设备云端同步。
- **已知限制**：
  - 链接进来的数据库与原数据库共用同一套视图、筛选和排序配置，不能在嵌入处单独设置。
  - 同一个同步块在同一个页面里放两份时，改其中一份后另一份需要刷新页面才会更新。
  - 删掉页面里的同步块不会删除底层的同步内容，无人引用的同步块内容仍会留在数据目录里。
  - 页面历史仅对正文页面生效，大约每 10 分钟保存一版，单个页面最多保留 40 版。
